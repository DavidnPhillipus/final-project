# Calendar App

A TypeScript React calendar app with event creation, editing, deletion, and local storage persistence.

## Features
- Monthly calendar layout
- Add, edit, and delete events
- All-day and timed events
- Color-coded event categories
- Event overflow handling for busy days
- Local storage persistence

## Run locally
1. Install dependencies:
   npm install
2. Start the dev server:
   npm run dev
3. Open the local URL shown in the terminal, usually http://localhost:5173/

## Production build
npm run build

## Notes
- The app is written in React + TypeScript.
- Event data is stored in localStorage so entries remain after refresh.
- The project uses Vite for bundling and development.
